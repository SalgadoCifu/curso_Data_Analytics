# Data Analytics — Repositorio de Prácticas

Repositorio dedicado a la consolidación de talleres, laboratorios y proyectos de la asignatura **Data Analytics**. El contenido abarca desde los fundamentos de programación en Python hasta la manipulación de datos tabulares, cálculo de KPIs y visualización descriptiva.

---

## Objetivo

Desarrollar habilidades técnico-analíticas mediante la resolución de problemas aplicados, utilizando **Python** y sus librerías especializadas para la limpieza, transformación, análisis exploratorio de datos y comunicación de métricas de negocio.

---

## Tecnologías Utilizadas

* **Lenguaje:** Python
* **Librerías:** Pandas, NumPy, Matplotlib
* **Entornos:** Jupyter Notebook / Google Colab

---

## Contenido por Semana

### Semana 1: Fundamentos de Python
* Configuración del entorno en Google Colab y Jupyter.
* Sintaxis básica, tipos de datos y estructuras de control.
* Lógica inicial para el procesamiento de información.

### Semana 2: Manipulación de Datos y Métricas
* Análisis tabular de datos con la librería Pandas.
* Agregaciones, filtrados y agrupaciones (`groupby`).
* Cálculo de indicadores de ventas y métricas clave de negocio.
* Visualización de resultados con Matplotlib.
